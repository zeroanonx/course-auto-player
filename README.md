# 课程自动连播助手（Chrome / Edge）

针对 `https://hbnun.lsedu.vip` 的课程播放页：点一下“开始”，插件会把每节视频直接拖到结尾，自动展开下一章并连播全部课时；**自动播放或切换被拦截时自动刷新页面继续**，全部完成后暂停。

## 安装（一次性）

1. 把 `course-auto-player` 整个文件夹放到一个固定位置（不要删）。
2. Chrome 地址栏打开 `chrome://extensions/`。
3. 右上角打开 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选择 `course-auto-player` 文件夹。
5. 刷新课程页 `https://hbnun.lsedu.vip/#/course/21/0`。

> Edge 同理：`edge://extensions/` → 开发者模式 → 加载解压缩的扩展。

## 使用

1. 打开课程播放页，左侧会出现 **“课程自动连播”** 浮窗（没有就点扩展图标里的“重新注入到当前页”，不必刷新）。
2. 点 **开始**。
3. 插件会从当前课时开始，依次完成本章和后续章节，遇到折叠的章节会自动展开；整门课全部完成后暂停。

浮窗上的选项：

- **静音播放**：默认开启，避免自动播放时突然出声。
- **进入课程页自动开始**：勾选后，下次打开课程页 2 秒后自动开始。
- **只完成当前页（做完就停）**：默认关闭。勾选后只完成当前节并立即暂停；不勾选时自动连播全部课时。
- **暂停 / 继续**：临时暂停；**停止**：结束本次运行。
- **自动刷新续播**：播放被浏览器拦截、视频加载超时或连续切不到下一节时，插件会自动刷新页面并从下一个未完成课时继续；连续刷新 4 次仍无进展会停下，避免无限刷新。

## 原理

1. 找到播放器里的 `<video>`，解除播放器对“未开始”课时的拖动限制，
   把 `currentTime` 设到 `duration - 0.2s`；
2. 播放 0.2 秒后触发站点自己的 `ended` 事件，站点按它原本的逻辑调用
   `saveLearnRecord` 记录进度并自动进入下一节；
3. 插件监听视频元素/视频地址变化确认已切换；若站点没有自动切换，
   会自动点击右侧章节列表里的下一节。当前章最后一节完成后，会自动展开下一章；
   全部课时完成后暂停，不会绕回开头。

插件不修改站点源码、不伪造接口请求、不上传任何数据；只会调整当前页面播放器的拖动限制，并把进度拖到结尾。

## 常见问题

**点了开始没反应 / 浮窗没出现？**
点浏览器工具栏里的扩展图标，按“重新注入到当前页”，不用刷新。仍不行时再刷新课程页。

**一直停在某一节？**
该节可能需要人脸识别、弹题或防挂机验证，插件不会绕过这些，需要手动完成后再点“继续”。

**为什么只学了一节就停了？**
检查浮窗里的“只完成当前页（做完就停）”是否被勾选；默认不勾选，应连续播放全部课时。

**自动播放被浏览器拦截？**
插件会先自动重试；仍然失败会自动刷新页面并继续播放。连续刷新 4 次仍被拦截时会停下，此时手动点一下视频再点“开始”。

**刷新后会自动接着学吗？**
会。刷新标记保存在当前标签页里，页面加载后约 3 秒会自动从下一个未完成课时继续。

**会影响已经学完的课时吗？**
不会，插件只处理当前课时和后面未完成的课时；连续模式下，已显示“已学100%”的课时会被跳过。

## 备用方法（控制台）

如果插件加载不了，也可以在课程页按 `F12` 打开控制台，粘贴执行（只处理当前这一节）：

```js
const v = document.querySelector('#ls-player-preview video');
if (v?.player?._options) {
  Object.defineProperty(v.player._options, 'disableSeek', {
    configurable: true, get: () => false, set: () => {}
  });
}
v.currentTime = v.duration - 0.2;
v.play();
```

## 说明

此类自动播放可能不符合平台的学习规则，请自行判断是否使用；建议先在一节课上试运行，确认进度能正常记录后再连续使用。
