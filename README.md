# 课程自动连播 + 考试自动答题助手（Chrome / Edge）

针对 `https://hbnun.lsedu.vip` 的两块功能：

- **课程自动连播**：检测到视频真正播放后接管，每节随机 5~10 秒播完并自动连播全部课时。
- **考试自动答题**：考试/作业页上的浮窗，自动完成“先提交一遍拿标准答案 → 再按答案提交一遍”的流程。

## 安装（一次性）

1. 把 `course-auto-player` 整个文件夹放到一个固定位置（不要删）。
2. Chrome 地址栏打开 `chrome://extensions/`。
3. 右上角打开 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选择 `course-auto-player` 文件夹。

> Edge 同理：`edge://extensions/` → 开发者模式 → 加载解压缩的扩展。

## 考试自动答题怎么用

1. 在浏览器里正常登录 `hbnun.lsedu.vip`（脚本不接管账号密码，只用你已登录的 cookie）。
2. 打开 **我的考试** 或 **我的作业** 页面（在课程页也可以，浮窗一样会出现）。
3. 右下角出现 **“考试自动答题”** 浮窗。
4. 选范围（考试 / 作业 / 两者），点 **开始**。

浮窗上的选项：

- **只做未完成的**：默认勾选。跳过已用完作答次数的项目，正在进行的会继续。
- **只做第一遍（刷答案）**：只提交一版把标准答案收进题库，不做第二遍。适合先攒题库。
- **停止**：当前步骤结束后停下。

### 它具体做了什么

平台把考试设计成可以重复提交（通知里也写了“提交一次后可以查看答案，再做第二次”）。脚本按这个流程跑：

1. 拉取试卷，并检查这份卷子之前有没有提交记录；有的话先把 `standardanswer` 收进本地题库。
2. 如果题库已经覆盖全部客观题 → 直接按标准答案提交一次，交完等批改出分。
3. 如果题库不全：
   - 先提交一版（题库有的用题库，没有的随机作答）；
   - 等系统批改完，从历史详情里取回标准答案入库；
   - 再提交一版全按标准答案作答的。
4. 客观题（单选 / 多选 / 判断）能全对。**填空题、简答题没有标准答案**，脚本不会编内容，这部分的分数需要你自己补。

### 题库

答案存在扩展的 `chrome.storage.local` 里，按“题型 + 题干 + 选项”做指纹索引，所以：

- 同一道题下次遇到会直接命中，不用再试错；
- 换试卷、换科目只要题目重复就能复用；
- 点扩展图标 → **导出答案库** 可以存成 JSON 备份。

题库为空时第一次跑会全部随机作答，这是正常的——那是为了拿到标准答案。

## 课程自动连播

1. 打开课程播放页，左侧出现 **“课程自动连播”** 浮窗（没有就点扩展图标里的“重新注入连播脚本”）。
2. 站点视频开始播放后，插件会自动接管；也可以手动点 **开始**。
3. 每节随机播放最后 5~10 秒后进入下一节；遇到折叠的章节会自动展开，整门课全部完成后暂停。

浮窗上的选项：静音播放、进入课程页自动开始、检测到视频播放后自动接管、只完成当前页、拖动 / 缩放 / 覆盖视频区、暂停继续、自动刷新续播（连续刷新 4 次仍无进展会停下）。

## 已知限制

- **最早交卷时间**：考试规则里有 `minminutes` 时，脚本会在浮窗日志里显示剩余等待时间，到点再交。这段时间页面需要保持打开。
- **批改慢**：平台提示评分要 1~5 分钟。脚本最多等 8 分钟，超时会提示“稍后再运行一次”，不会丢进度（题库已经存了）。
- **作答次数**：`timeslimit` 用完的项目会跳过。只剩 1 次机会时只能尽量作答，无法做两遍。
- **主观题**：填空题、简答题需要你自己答。
- **登录失效**：日志出现“登录已过期”时脚本会停止，重新登录后再点开始即可。

## 说明

这类自动化是否符合平台规则请自行判断，建议先在一门考试上试运行，确认成绩能正常记录后再批量使用。
